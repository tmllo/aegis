- CelesTrak elements reload at build and server start, not on a 6 h poll, until `test_live.py` stops requiring `refreshed == ["isslive"]`. A process left running keeps the elements it loaded at startup.

- `web/src/console/entries.ts` `saveEntry` (used by `CrewPage` and `InfoSheet`) only posts blood pressure, heart rate, temperature and glucose. Sleep, mood and exercise typed there stay on the device. The slider (`vitals/MetricSlider.tsx`) does post `self.sleep_h`, `self.mood` and `self.exercise_min`. Add those three keys to `VITAL` in `entries.ts` if the organ panel should store them too. Glucose in that map is `vital.glucose`; the server now stores it as `lab.glucose`, so that one does not need a web change.
