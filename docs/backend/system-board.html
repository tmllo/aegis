02 · How the backend is organized

Store each fact once, compute everything else

Database normalization applied to the whole backend. Every source goes through its own adapter into four kinds of fact, checked against one catalog. One engine derives scores and forecasts. Views shape the output for each screen. Arrows only go right: a new source is one adapter, a new screen is at most one view. Full design: docs/backend/DATA-CORE.md.
