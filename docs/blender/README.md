# Blender: Ana in the e^x sensor layer

| Path | What |
|---|---|
| `renders/` | 4K stills: Ana at the ISS Cupola (front shows the suit sensors, back shows Earth); first suit concept |
| `scripts/` | Background-Blender scripts: `make_ana.py` (MPFB body), `hero_cupola.py` (scene, `front` or `back`), `export_web_glb.py` (web model) |
| `sources/` | Free asset sources with licenses and credit lines |

Web model: `web/public/models/ana-suit.glb` (nodes: body, suit, sensor_heart, sensor_lungs, sensor_head, sensor_wrist).
The full asset library (about 6 GB) stays local in `NASA PROJECT/blender-assets/`, too big for git.

Credits: MakeHuman/MPFB assets CC0; NASA Blue Marble and Black Marble (public domain); clouds by Solar System Scope (CC BY 4.0).
