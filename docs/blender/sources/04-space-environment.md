# 04 - Space environment: sources

Environment, lighting and context for cinematic astronaut shots. Every file was downloaded straight from the source. No logins, no keys. Downloaded 2026-11-15.
Poly counts and sizes come from a background Blender 5 import (`--factory-startup --disable-autoexec`). "Size (units)" is the bounding box after import. No model is at real-world scale, so scale it after import.
