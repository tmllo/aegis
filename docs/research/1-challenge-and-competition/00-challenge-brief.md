# Challenge brief: Create Health Monitoring Software for Astronauts on Space Missions

Source: https://www.spaceappschallenge.org/2026/challenges/health-monitoring-software/
Event: 2026 NASA Space Apps Challenge (14-15 November 2026) | Difficulty: Intermediate
Subjects: Human Exploration, Software, Space Exploration
Captured: 2026-11-14 (read from the live page)

## The task (in one line)
Build a **visual tool** that gathers health indicators and lets astronauts **assess their own health** during a mission and get **guidance on treatment and improvement**.

## Key facts from the page
| Item | Detail |
|---|---|
| Problem | Long missions: radiation, isolation/confinement, altered gravity, hostile closed environment, distance from Earth. Effects: immune changes, bone loss, cardiovascular events, poor nutrition, behavioral health. |
| Who acts | Astronauts must spot changes in themselves (ground support is far away). |
| Example indicators | Blood pressure, heart rate, blood sugar, body temperature, daily sleep hours, mood. |
| Allowed input | Anything: keyboard text, mouse clicks, camera images, ultrasound images, values like blood sugar in mg/dL. |
| Questions to answer | Which measurements can be done in space? Why is an exam needed? How do hazards affect each indicator? When should a result go to the crew or to flight surgeons on the ground? What actions prevent a critical condition? |
| UI hint | Clear metrics and diagnosis; animation and interactivity; e.g. a clickable human body figure showing each part's function and status. |

## Optional ideas the page suggests
- Works in different settings: spacecraft, station, rover, lunar/Mars base.
- Prompts astronauts to take measurements on a routine schedule.
- Gamification for health tasks.
- Dynamic charts over time.
- Color coding for at-a-glance status.
- Simple instructions: do not assume astronauts know how to assess health.
