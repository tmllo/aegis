# 08 Open-source health software: what to learn from and reuse

Captured: 2026-11-14. Scope: open-source health and health-monitoring software we can learn from or legally reuse in a hackathon web app. Not repeated here: data inputs (Web Bluetooth, vitallens.js, MobiVital, Synthea, FHIR/LOINC table) are in `04-prototype-data-sources.md`; other teams' entries are in `06-competitor-analysis.md`.
Method: Wikipedia list read as raw wikitext; GitHub stars and last push read with `gh api` on 2026-11-14; Codeberg and GitLab read through their public APIs.
Marking: **[unverified]** = not confirmed from a primary source today; **[3rd-party]** = only a secondary source found.

## Summary

| # | Finding |
|---|---|
| 1 | **The Wikipedia list is mostly hospital EHRs and imaging tools.** Too heavy to embed in 48 h. The useful parts are design patterns: OpenMRS O3 vitals UI, GNU Health's personal record (MyGNUHealth), Nightscout's glanceable displays, OpenAPS "autosens" personal sensitivity, CHT and DHIS2 offline sync. Almost all are active in Nov 2026. |
| 2 | **Several big names are copyleft** (OpenEMR GPL-3.0, Nightscout and AndroidAPS AGPL-3.0, CHT AGPL-3.0, Gadgetbridge AGPL-3.0). Copy ideas, not code. Permissive and safe to reuse: Medplum, HAPI FHIR, fhirclient (Apache-2.0); DHIS2, Tidepool (BSD); oref0 (MIT). |
| 3 | **Most creative finds:** hGraph ("your health in one picture", a radial chart with a normal band, Apache-2.0); Nightscout Clock and Koboscout (ambient desk and e-ink displays); RHR-Diff and AnomalyDetect (Stanford, personal-baseline anomaly detection, MIT); Pulse Physiology Engine (open whole-body physiology simulator, Apache-2.0); OpenHRV (HRV biofeedback breathing pacer); Wi-Fi CSI and mmWave radar breathing sensing. |
| 4 | **Reusable assets with clean licences:** Human Reference Atlas 3D organs (GLB, CC BY 4.0); BodyParts3D (now CC BY 4.0 per DBCLS, updated 2025-02-27); Häggström body diagram SVGs (CC0 / public domain, check each file); react-body-highlighter and body-muscles (MIT / Apache-2.0). **Avoid for a permissive repo:** Z-Anatomy (CC BY-SA 4.0, share-alike, some parts NC); rPPG-Toolbox (RAIL licence, use restrictions). |
| 5 | **NEWS2 can be used freely with credit.** The RCP lifted copyright on NEWS2 if it is credited and its charts are not modified. A NEWS2-style points table is a cited, transparent basis for a "crew early-warning score". It is not validated for spaceflight, so label it as adapted. |
| 6 | **Top 5 ideas to adopt** (table D): radial "one picture" status; a NEWS2-derived score; a personal-baseline drift detector modelled on RHR-Diff and autosens; an HRV breathing pacer as the guidance action; a glanceable ambient "night face". |

## Licence rules for our hackathon web app

| Licence | Can we copy code into our app? | Conditions | Source |
|---|---|---|---|
| MIT, BSD-2/3, Apache-2.0 | Yes | Keep the copyright and licence notice; Apache-2.0 also keeps NOTICE and states changes | [choosealicense.com](https://choosealicense.com/licenses/) |
| MPL-2.0 (OpenMRS) | Yes, file by file | Modified MPL files stay MPL and their source must be offered; our own files can use any licence | [MPL 2.0 FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/) |
| LGPL-2.1/3.0 | Use as an unmodified library: yes. Copying code into our files: our files become LGPL | Users must be able to swap in a modified library | [GNU licences](https://www.gnu.org/licenses/licenses.html) |
| GPL-3.0 | Only if our whole app is released as GPL-3.0 | Source must be offered with any distribution | [GNU GPL](https://www.gnu.org/licenses/gpl-3.0.html) |
| AGPL-3.0 | Only if our whole app is AGPL-3.0; serving it over the web counts as distribution | Source must be offered to network users | [GNU AGPL](https://www.gnu.org/licenses/agpl-3.0.html) |
| CC BY 4.0 (assets) | Yes | Visible attribution (on the Sources screen and in the Space Apps references) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| CC BY-SA 4.0 (assets) | Yes, but adapted assets must also be CC BY-SA | Keep the asset in its own folder with its licence | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| CC0 / public domain | Yes | Credit is courteous, not required | [CC0](https://creativecommons.org/publicdomain/zero/1.0/) |
| RAIL / "Responsible AI" licences | Read the use restrictions first | Use-based restrictions; not OSI open source | [licenses.ai](https://www.licenses.ai/) |

Practical rule: read copyleft code for ideas and write our own; vendor only MIT/BSD/Apache code and CC0/CC BY assets. Ideas, algorithms and published thresholds are not copyrightable; the code is.
